# Hlídač letenek – eurovíkend

Stránka s nejlevnějšími víkendovými letenkami (Ryanair) pro partu z Prahy a z Moravy.
- `index.html` – frontend (bez buildu)
- `api/scan.js` – Vercel funkce, tahá ceny z veřejného Ryanair API, cache 3 h
- Nasazení: import repozitáře na vercel.com/new, framework „Other“, žádný build.
